Jump & Run

Jump & Run is een 2D platform game waarin je springt, rent en obstakels ontwijkt. De game draait om timing en snelle reacties. Elke level wordt steeds een beetje moeilijker.

Onze studio

101 Games is een kleine game studio die is opgericht als schoolproject. Wij werken met een klein team en leren hoe games worden gemaakt. Onze focus ligt op 2D games met een kleurrijke stijl en duidelijke gameplay over het spel.

De game

In Shadow Jump bestuur je een personage dat door verschillende levels springt. Je moet platforms halen, obstakels ontwijken en goed timen wanneer je springt. De game begint makkelijk, maar wordt steeds uitdagender.Het doel van de game is om elk level te halen zonder geraakt te worden. Door te oefenen word je steeds beter en sneller.
